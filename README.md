## 01 / Flagship — MemOps

> **Operational memory infrastructure for AI and production systems.**

| | |
|---|---|
| **Problem** | Operational knowledge (incident resolutions, root causes, config decisions) scatters across tools, decays, contradicts itself, and can't be retrieved reliably when it's needed. |
| **System** | A multi-tenant REST API + CLI for storing, versioning, retrieving, and diagnosing operational memories — with evidence and provenance attached to every entry. |

**Engineering signals**

```
Hybrid ranking      →  vector similarity · lexical match · confidence decay
                        environment fingerprint · lifecycle state  (5 weighted signals)
Memory lifecycle     →  PROPOSED → CONFIRMED → SUPERSEDED → CONTRADICTED → ARCHIVED
Diagnosis engine     →  deterministic, no LLM dependency, fully auditable
Architecture         →  Domain → Application → Infrastructure → Interface → Agents
Access & reliability →  scoped API-key RBAC · sliding-window rate limiting · OpenTelemetry
Verification         →  unit / integration / e2e test suites, CI-gated
```

`FastAPI` `PostgreSQL` `pgvector` `SQLAlchemy` `OpenTelemetry` `Poetry` `Docker`
